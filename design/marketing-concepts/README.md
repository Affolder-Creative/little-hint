## Fidelity and implementation notes

All app screens and product images in these boards are generated illustrations, not actual application screenshots. Their individual controls, tabs, wording, icons, data, and navigation may differ from the application. Replace them with real captures from isolated demonstration data before publishing. Preserve the application's actual surprise/privacy behavior. Use the original approved SVG logos in the finished website, not generated logo pixels.

B's generated hero uses serif lettering despite the original sans-serif direction; the rendered board is the proposal being presented. C includes cropped app details as part of the composition. For production, verify those crops keep the relevant state understandable and do not clip interactive webpage content.

Audience: self-hosters who want gift coordination for families and friends. Primary action: Self-host Little Hint. Secondary action: View on GitHub. One selected static page, no public signup, analytics, custom domain, or payment processing.

The selected direction is implemented in `marketing/`, with a dedicated GitHub Pages workflow that publishes only that directory. Expected default URL: https://kaffolder7.github.io/little-hint/ subject to repository configuration. See `docs/MARKETING.md` for setup and screenshot provenance.
