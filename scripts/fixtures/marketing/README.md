# Marketing product-photo fixtures

Original images generated with the built-in Imagegen tool on November 4, 2026. These depict illustrative, unbranded gifts, not retail products. The capture script serves these local WebP files through fixture media responses. No external image service is contacted.

Each output is resized to 640 × 640 and encoded as WebP at quality 85. The following are the exact generation prompts.

## gift-0.webp

Create one square product photo for an illustrative gift-list app fixture: a cream ceramic pour-over coffee dripper with matching mug. Warm natural window light, soft ivory tabletop, subtle realistic shadow, centered entire object with generous room around it. Tasteful catalog photography, tactile materials, muted earthy colors. No text, brand marks, logos, watermarks, people, UI or borders. Output one image.
