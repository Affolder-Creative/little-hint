# Repeat an annual event

An owner or appointed event leader can open **Event actions → Repeat event**
from an active or archived group event, including its row in My lists.

The form starts with the previous description, spending guideline, privacy
choice, time zone, and participant selections. People who no longer belong to
the family group are omitted with an explanation. New members are not selected
automatically. Review the new name and selections before creating the event.

Archive and gift-summary dates start blank so an old schedule cannot archive
or reveal the new occasion immediately. Choose new dates if needed. New events
can have a different privacy policy; the original event's policy remains locked.
The final review identifies the selected people, sharing policy, archive date,
and spending guideline.

Repeating creates a separate, active event in the same family group and one
fresh, empty wish list per selected person. It does not copy items, reservations,
purchases, contributions, private notes, spending records, or secret exchanges
and assignments. The original event, its lists, and its history remain unchanged.
This is a manual repeat action, not an automatic yearly recurrence.

The server rechecks organizer access, source revision, current participant
eligibility, and date validity. Dates that have already elapsed in the selected
time zone are rejected. Retried requests reuse the new event ID without making
duplicate events or lists. No database migration is required.
